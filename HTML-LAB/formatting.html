HTML Text Formatting

HTML provides elements that change the appearance of text or describe its meaning. Each example below demonstrates a text formatting tag.

Bold Text

The <b> tag draws attention to text without giving it extra importance. It usually appears bold.

Example: The keyword for today's lesson is formatting.

Important Text

The <strong> tag marks text as important. Browsers usually display it in bold.

Example: Save your work before closing the browser.

Italic Text

The <i> tag identifies text in an alternate voice, such as a technical term or a phrase in another language. It usually appears italic.

Example: The phrase bonjour means hello in French.

Emphasized Text

The <em> tag adds stress emphasis to text. Browsers usually display it in italics.

Example: I really enjoy learning HTML.

Underlined Text

The <u> tag marks an annotation, such as a spelling error, and usually underlines the text.

Example: The word recieve is misspelled; the correct spelling is receive.

Highlighted Text

The <mark> tag highlights text that is relevant in the current context.

Example: In these search results, the matching term is HTML.

Small Text

The <small> tag represents side comments or fine print. It usually appears smaller than surrounding text.

Example: This page was created for a classroom activity.

Deleted Text

The <del> tag marks text that has been removed from a document. It usually appears with a line through it.

Example: My previous hobby was collecting stamps.

Inserted Text

The <ins> tag marks text that has been added to a document. It usually appears underlined.

Example: My new hobby is photography.

Subscript Text

The <sub> tag places text below the normal baseline, such as numbers in chemical formulas.

Example: The chemical formula for water is H2O.

Superscript Text

The <sup> tag places text above the normal baseline, such as exponents in mathematical expressions.

Example: Five squared is written as 52 = 25.
